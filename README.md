## Features

- **Main Game in Center** - Game canvas is perfect centered
- **Status Bar Above Game** - Score, Level, Foods, Length in center
- **Leaderboard Below Game** - Leaderboard, foods, settings in center
- **3 Modes from JSON** - Classic, walls, speed
- **4Foods from JSON** - Red berry, gold star, shield, Ghost
- **live stats + Progress bar**
- **Leaderboard from `database.json`**
- **High Score Saved** - Using `localstorage`
- **Mobile Controls** - Arrow buttons
- **keyboard controls** - WASD + space

## How to Play

| Key | Action |
|-----|--------|
| `⬆️`/`W` | Move Up |
| `⬇️`/`S` | Move Down |
| `⬅️`/`A` | Move Left |
| `➡️`/`D` | Move Right |
